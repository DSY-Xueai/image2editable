# 叶组件拆分与文字残影门禁设计

## 目标

修复两个通用问题：

1. Agent 将多个可独立移动的视觉实体合成一个大图片组件。
2. 最终视觉组件仍携带栅格文字、浅灰字印或文字透明洞。

本设计统一作用于图片、PDF、图片版 PPTX，以及混合 PPTX 中被批准重建的截图对象；不按文件名、内容主题或测试样例分类。

## 已确认的输出语义

- 视觉输出采用“最小完整视觉单元”：对象可独立移动，内部边框、底色、图标和必要阴影保持完整。
- 箭头、连接线、相邻卡片、外层容器和其他可独立移动对象分别输出。
- 语义父级只记录组合关系，不把多个叶组件烘焙成一张图片。
- 所有可靠文字输出为原生可编辑文字框；视觉组件不得包含文字像素。
- 每页最多五个重修批次。仍无法同时满足拆分和去字门禁时，仅该页保留原图并明确报告失败，其他页面继续处理。

## 根因

真实 `test1.pptx` 首轮 CV 已生成卡片、箭头、图标和局部图形候选，但 Host 计划以“构成完整流程图”为由调用 `absorb_into_parent`，把多个独立实体吸收到整块 RAG/Graph RAG 父组件。现有契约只验证动作角色和像素完整性，没有验证输出是否过度合并。

现有文字质量主要评价整页重建。整页看起来接近源图时，系统无法证明：

- 单独导出的组件图片不含文字像素；
- 移走组件后的背景没有原文字残影；
- 最终画面中的文字只来自可编辑文字层。

## 设计一：叶组件优先与过度合并门禁

### Agent 规则

Host 与 Local 使用相同规则：

- 语义相关不等于应合并。
- `absorb_into_parent` 只用于同一物理实体的重复掩码、碎边、阴影或分割缺口。
- Agent 必须用“单独移动后是否仍完整”的反事实标准判断叶组件。
- 父级可以表达流程、表格或科研图等组合关系，但默认不参与最终像素渲染。

### 确定性门禁

新增硬违反项 `over_merged_component`。门禁复用现有组件图、父子来源和掩码，不引入内容类别规则。

对每个计划冻结的父组件：

1. 收集被其吸收的原始候选及对应掩码。
2. 按显著像素重叠和相互包含关系聚成“同一实体候选簇”；同一物体的重复检测进入同一簇。
3. 忽略面积低于页面自适应噪声下限的碎片。
4. 若父组件包含两个或更多空间独立、各自达到有效面积的候选簇，则判为过度合并。

违反后父组件不能冻结或进入 donor，必须在下一批由 Agent 改为保留叶组件、仅合并重复候选或重新分割。第五批后仍失败则该页保留原图。

## 设计二：组件、背景与文字三层隔离门禁

新增硬违反项 `component_text_residual`，并把文字验证拆成三个独立视图：

1. **组件视图**：只渲染一个最终叶组件到透明画布。OCR 掩码与其邻域内不得存在可识别字形、浅灰笔画或文字形连通区域。
2. **背景视图**：不渲染任何视觉组件或文字。原文字区域不得保留相对局部底色可见的字形残影。
3. **合成视图**：背景、叶组件和可编辑文字合成后与源图比较；同一文字只能由一个可编辑文字对象贡献，不允许栅格文字与文字框同时出现。

检测继续使用页面自适应噪声、局部底色、OCR 掩码和连通区域，不使用固定颜色或特定语言规则。Agent 证据包增加组件隔离联系表，使 Host/Local 能看到单个组件而不是只看整页。

当前 PPTX donor 已使用 `text-clean` RGB 和完整组件 alpha；新门禁在最终组件资产发布前再次验证，防止后续合并或重修把文字重新带回组件。

## 状态与降级

- 两项新违反都进入现有页面级批量重修循环，不增加第六批。
- 通过的叶组件继续不可变冻结，不因其他组件失败而重新处理。
- `over_merged_component` 或 `component_text_residual` 未解决时不得标记 `ready_for_assembly`。
- 五批结束仍失败时，页面状态为 `preserved_with_warning`，输出使用完整原页，不输出伪可编辑组件。
- 降级必须在摘要中列出具体违反项，不能当作完整成功。

## 范围控制

本轮不新增模型、不下载模型、不引入内容分类器、不重写 OCR/CV/SAM，也不把图片组件承诺为原生矢量或 SmartArt。只修改 Agent 指令/证据、组件动作约束、质量门和相应测试。

## 验收

- 合成通用布局中，多个相邻但可独立移动的卡片、箭头和图形不能被一个渲染父组件吞并。
- 同一实体的重复掩码仍可合并，不因新门禁产生重复组件。
- 组件隔离图不含 OCR 文字像素，背景隔离图无文字残影，最终文字对象可编辑且只出现一次。
- 图片、PDF 和截图型 PPTX 共用同一门禁；未命中的混合 PPTX 原生对象保持不变。
- `test1.pptx` 重新验收时，RAG/Graph RAG 流程输出为多个最小完整视觉单元，不再是整块父组件。
- 全量自动化测试、PowerPoint 原生重开和渲染检查通过；资源策略继续保持重型页面串行。
