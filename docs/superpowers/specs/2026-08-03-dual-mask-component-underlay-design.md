# 双遮罩组件底图重建设计

## 目标

让图片、PDF、图片版 PPTX 以及获准转换的混合 PPTX 截图区同时满足：文字保持可编辑、视觉组件不含栅格文字、父子组件可独立移动，并且不出现重影、空洞、白色补丁、色带或浅灰残影。未命中的 PPTX 原生对象保持不变。

本设计不增加模型下载，不区分表格、科研图或卡片等固定图片类别，Host/Local Agent 继续互不依赖，每页最多五个重修批次保持不变。

## 根因

当前组件 mask 同时承担两个冲突职责：

- 源像素 ownership 要求每个源像素只有一个所有者，用于阻止重复阴影和文字重影。
- PowerPoint 组件 alpha 必须形成可独立移动的完整视觉对象；父组件被子图标或文字遮挡的区域需要连续底色。

当唯一 ownership 从父组件中扣除文字或子组件区域后，父组件出现空洞。当前最近邻填补会在渐变、纹理和复杂底色上形成放射状补丁或横向色带。Agent 可以判断层级和重试边界，但无法通过重复同一 mask 动作修复这项表示层冲突。

## 设计

每个活动视觉组件保留两类互不替代的遮罩：

1. `ownership mask` 继续保存在组件图中，只表示真实源像素归属。不同组件的真实源像素必须唯一，现有重复像素、文字残留和越界门禁继续生效。
2. `presentation alpha mask` 在每轮证据、质量检查和最终导出时由哈希绑定的源图、组件图与父级语义遮罩确定性派生。它由 ownership 区域与合法 underlay 区域组成，用于生成完整可移动对象。

合法 underlay 只能位于当前组件的父级语义范围内，并且必须是被更高层子组件或冻结文字遮挡的内部区域；不得扩张到父级边界外。每个 underlay 像素记录为生成像素，不能伪装成真实源像素，也不能跨图片、跨页或跨批复用。

## 底色重建

执行器只在单个组件的紧 bbox 和有界上下文中处理 underlay，不创建重复整页浮点数组。对同一 repair mask 生成两种确定性局部候选：Telea 与 Navier-Stokes inpaint；按“边界平均色差、边界梯度突变 p95、新增高频像素数”的字典序选择较小者，完全相等时固定选择 Telea，不使用按图片类别配置的权重。

Agent 不直接生成像素。Agent 继续负责语义职责：判断父子关系、是否应该拆分、组件边界是否完整，以及失败后选择 retry/split/collapse 等动作。像素修补始终由本地确定性执行器完成，避免 Host 模型差异改变最终底色。

## 质量门禁与证据

- ownership 唯一性只检查真实源像素；仅在 `generated_underlay_mask` 标记范围内允许 presentation alpha 与子组件重叠。
- 新增 underlay 边界接缝、梯度突变、高频补丁和文字残留检查；任何硬失败不能被 Agent confidence 放宽。
- `component-isolation.png`、重建图和最终导出都使用 presentation alpha 与重建后的 RGB，避免 Agent 看到的证据和用户得到的 PPTX 不一致。
- 质量报告显式记录 ownership、presentation alpha、generated underlay 的哈希与指标，所有派生物限定在当前页当前批次。
- 五批后仍不能生成合格完整组件时，该页进入 `preserved_with_warning`，不通过清空组件、隐藏失败或栅格文字兜底伪装成功。

## 数据流

`Agent 计划 → ownership 图动作 → 父级语义范围求 underlay → 有界双候选修补 → presentation 组件证据 → 质量门禁 → 冻结或下一批 → PPTX 导出`

组件图的既有 ownership mask 和 Agent 动作契约保持兼容；presentation/underlay 属于逐轮派生资产，不允许修改已冻结组件或原始父级资产。

## 测试与验收

- TDD 覆盖纯色、横纵渐变、纹理、线条图、嵌套卡片、文字洞和子图标洞；旧最近邻实现必须在色带/接缝测试上失败。
- 验证真实源像素仍唯一、生成 underlay 只在允许区域、文字不回到视觉组件、冻结组件不被后续批次改写。
- 验证每组件紧 bbox 的内存上限，并确保真实文件继续串行处理。
- 重新以全新 Run 验收 `test1.pptx`，再回归 `wsl和虚拟机对比.png`；最终用 PowerPoint COM 重开、逐页原生渲染和删除全部可编辑文字后的图片层检查组件完整性与残影。

## 非目标

- 不加入按表格、科研图、卡片等类别写死的分支。
- 不引入生成式图像模型、在线 API 或转换时模型下载。
- 不改变混合 PPTX 未命中原生对象的保留规则。
- 不放宽现有文字残留、重复阴影、页级失败和五批上限。
